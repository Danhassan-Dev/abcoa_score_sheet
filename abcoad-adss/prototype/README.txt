# ABCOAD Digital Examination Score Sheet Archive (ADSS) — Frontend Mockup

## Files
- `index.html` — page structure and screens
- `styles.css` — responsive Noviq-inspired interface styling
- `app.js` — navigation, sample archive records, upload validation, search/filter, preview modal, verification interactions
- `logo.png` — supplied Audu Bako College of Agriculture logo

## Run
1. Keep all four files in the same folder.
2. Open `index.html` in a modern browser (Chrome, Edge or Firefox).
3. No build tools or package installation are required.

## Included screens
Dashboard, Upload Score Sheet, Document Archive, Verification Centre, Staff Management, Activity Logs and System Settings.

## Important prototype limitations
This is a frontend-only mockup. Uploaded files and records are held in browser memory only and will be lost on refresh. It does not yet include login authentication, server-side file storage, MySQL, access control or secure backups. These will be implemented in the PHP/MySQL version.
